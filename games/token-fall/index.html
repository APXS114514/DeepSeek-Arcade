🐳 TOKEN FALL

← → / A D 移动　·　接 TOKEN / HEAVY，躲 NOISE，抢 COMPRESS　·　P 暂停

屏幕顶部落下 TOKEN（蓝）/ COMPRESS（青）/ HEAVY TOKEN（绿，方块里写着 H）/ NOISE（紫）/ THINK（金）。 接 TOKEN 得分但 CONTEXT +32；COMPRESS 压缩 Context，但效果随 LOAD 提升而减弱（−256 → −128）， 短时间内连吃还会边际递减（100% → 75% → 50%），Context 越低收益也越小 —— 所以不是见到就接。 HEAVY TOKEN 一次 +35 分，代价是 CONTEXT +96，是中后期典型的「高分 vs 风险」选择；它算有效 Token，CLEAN 连击继续涨。 NOISE 不加分，CONTEXT +128 ~ +224，LOAD 越高越致命，必须躲开。 游戏分 LOAD 1~5 五个阶段（约 0 / 30 / 60 / 100 / 150 秒）：LOAD 越高，C 越稀有、NOISE 越狠、Overflow 抢救时间越短（2.0s → 1.2s）， 所有数值 150 秒后封顶 —— 后期很难，但不会「玩得够久必定数值爆炸」。CONTEXT 满 1024 后进入抢救期，吃到 COMPRESS 把 Context 压回 1024 以下即可取消溢出。 最高分存在本地浏览器里。
